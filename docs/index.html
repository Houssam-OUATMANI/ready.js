WALKTHROUGH

Quick Start

Build a complete REST API with global middleware, typed route parameters, typed body payloads, and universal multi-runtime startup in under 30 lines.

TS server.ts 
import { Ready } from "ready-framework";

const app = new Ready();

// 1. Global Middleware: response-time header
app.use(async (c, next) => {
  const start = performance.now();
  await next();
  const ms = (performance.now() - start).toFixed(2);
  c.header("X-Response-Time", `${ms}ms`);
});

// 2. GET with auto-coerced parameter and query
app.get("/api/users/:id", (c) => {
  const id = c.req.param<number>("id"); // typeof id === "number"
  const limit = c.req.query<number>("limit") ?? 10;

  return c.json({
    id,
    limit,
    name: `User #${id}`,
  });
});

// 3. POST with generic typed JSON body
interface CreateUserDto {
  name: string;
  email: string;
}

app.post("/api/users", async (c) => {
  const body = await c.req.body<CreateUserDto>();

  if (!body.name || !body.email) {
    return c.json({ error: "Missing required fields" }, 400);
  }

  return c.json({ id: 1, ...body }, 201);
});

// 4. Universal listen (Bun, Node, Deno automatically detected)
const server = await app.listen({ port: 3000 });
console.log(`Server listening on http://${server.hostname}:${server.port}`);
API REFERENCE

Request Handling (c.req)

The ReadyRequest wrapper encapsulates the Web Standard Request instance and enhances it with automatic type coercion, query parsing, and cached JSON reading.

c.req.param<T>()

Extracts dynamic path segments (e.g. :id). Automatically coerces strings like "42" into numbers or booleans.

c.req.query<T>()

Extracts single search parameters or coerces the entire query string into a fully typed TypeScript record.

c.req.body<T>()

Parses the JSON request stream into a strongly-typed DTO. Automatically caches the result for multiple reads.

TS Type Coercion Demonstration 
// 1. Automatic param conversion
const id = c.req.param<number>("id");             // "123" ➔ 123 (number)
const isActive = c.req.param<boolean>("active");   // "true" ➔ true (boolean)

// 2. Custom explicit transformer
const bigId = c.req.param("id", BigInt);            // BigInt("123")

// 3. Strongly-typed full query object
interface CatalogFilters {
  limit: number;
  offset: number;
  inStock: boolean;
  search?: string;
}
const filters = c.req.query<CatalogFilters>();

// 4. Header inspection
const authHeader = c.req.header("authorization");
const rawRequest = c.req.raw; // Native Web Standard Request
API REFERENCE

Context Object (Context)

The Context is passed to every route handler and middleware. It provides fluent setters for headers, status codes, state management, and JSON response formatting.

TS context-usage.ts 
// Returning formatted JSON response with custom HTTP status code
return c.json({ message: "Resource created" }, 201);

// Fluent chained header configuration
c.header("Cache-Control", "no-store, max-age=0");
c.header("X-Rate-Limit-Remaining", "99");
c.status(200);

// Context state sharing across middleware stages
c.set("currentUser", { id: 42, role: "admin" });

// Retrieve state in downstream route handler
const user = c.get<User>("currentUser");
ENGINE ARCHITECTURE

Radix Tree Router

Ready implements an internal Radix Tree (compact Trie) router that matches paths in O(k) time where k is the path segment depth, rather than iterating through linear regex chains. Supports dynamic segments and wildcard cascades.

Static Match

/api/v1/health
Matched via direct map lookup.

Dynamic Parameters

/users/:userId/posts/:id
Captures multiple keys cleanly.

Wildcards

/public/*
Matches any suffix subpath cascade.

TS Modular Sub-Routing via app.route() 
// Sub-router for Authentication
const auth = new Ready();
auth.post("/login", async (c) => c.json({ token: "jwt..." }));
auth.post("/logout", async (c) => c.json({ success: true }));

// Sub-router for Products
const products = new Ready();
products.get("/", (c) => c.json([{ id: 1, name: "Keyboard" }]));
products.get("/:id", (c) => c.json({ id: c.req.param<number>("id") }));

// Mount to main application
app.route("/api/auth", auth);
app.route("/api/products", products);

// Endpoints created:
// POST /api/auth/login
// POST /api/auth/logout
// GET  /api/products
// GET  /api/products/:id
PIPELINE ARCHITECTURE

Onion Middleware Model

Ready uses Koa-style cascading middleware. Calling await next() pauses current execution, executes downstream handlers, and resumes back for post-processing.

TS middleware-pipeline.ts 
// Global Logger Middleware
app.use(async (c, next) => {
  const start = performance.now();
  
  await next(); // <-- Executes route handlers and downstream middleware
  
  const elapsed = (performance.now() - start).toFixed(2);
  console.log(`[${c.req.method}] ${c.req.pathname} -> ${elapsed}ms`);
});

// Path-Scoped Middleware with Wildcard
app.use("/api/admin/*", async (c, next) => {
  const token = c.req.header("Authorization");
  if (!token || !token.startsWith("Bearer ")) {
    return c.json({ error: "Unauthorized", status: 401 }, 401);
  }
  await next();
});
TS Centralized Error Handlers 
// Custom Global 500 Exception Handler
app.onError((err, c) => {
  console.error("Internal Exception:", err);
  return c.json({
    error: "Internal Server Error",
    message: err.message,
    statusCode: 500
  }, 500);
});

// Custom 404 Route Not Found Handler
app.onNotFound((c) => {
  return c.json({
    error: "Not Found",
    path: c.req.pathname,
    statusCode: 404
  }, 404);
});

TYPESCRIPT CONTRACTS

Type Declarations & Exports

All primitives, handlers, middlewares, and configuration structures are strictly typed and exported from the root module.

TS Available Types 
import type {
  HttpMethod,       // "GET" | "POST" | "PUT" | "PATCH" | "DELETE" | "OPTIONS" | "HEAD" | "ALL"
  Handler,          // (c: Context) => Response | Promise | unknown
  Middleware,       // (c: Context, next: NextFunction) => Promise | void
  NextFunction,     // () => Promise
  ErrorHandler,     // (err: Error, c: Context) => Response | unknown
  NotFoundHandler,  // (c: Context) => Response | unknown
  RouteParams,      // Record
  RouteMatch,       // { handlers: Handler[], params: RouteParams }
  ServerOptions,    // { port?: number, hostname?: string }
  ServerInstance    // { port: number, hostname: string, close: () => void }
} from "ready-framework";
